- Fluxo padrão: ChatGPT/Codex altera o GitHub → a Vercel detecta o commit → publica automaticamente no mesmo domínio.
- Fonte oficial do projeto: branch `main` do GitHub.

## Preferência de trabalho do usuário

- Trabalhar com autonomia e avançar sem perguntas desnecessárias.
- Fazer correções, melhorias técnicas, commits, testes e atualizações de publicação quando forem claramente necessárias para concluir o pedido.
- Perguntar apenas quando faltar uma decisão que altere materialmente o resultado, quando forem necessários senha, OTP, login ou ação manual do usuário, ou quando uma confirmação de segurança for obrigatória.
- Não pedir novamente informações que já estejam disponíveis no projeto, no repositório ou nas conversas deste Projeto.
- Após cada alteração, validar o build, confirmar o deployment da Vercel e testar o site público.

## Observações

- Atualizações do site existente não exigem recriar GitHub, integração ou projeto Vercel.
- Um site completamente novo exige um novo repositório/projeto, mas as contas já estão preparadas.
- Autorizações podem precisar ser renovadas se uma sessão ou integração expirar.
- Regras obrigatórias de segurança da plataforma continuam valendo, mesmo com esta preferência por autonomia.
